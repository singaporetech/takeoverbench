# HCMTP Metric Calculations & Assumptions

This document states exactly how each of the 41 HCMTP metrics is calculated in TakeoverBench, what we assume where the paper is silent, and whether the current code matches the paper.

## Global assumptions

- **Measurement window:** all telemetry rows from the TOR until the scenario auto-ends. The paper (Table II) says "after the TOR" but gives no duration, so we fix the window as TOR to end-of-run.
- **Sampling:** CARLA telemetry is sampled at ~30 Hz; brief peaks may be missed.
- **Steering units:** CARLA `steer` is a normalized command in [-1, +1]. We convert to degrees with `steer x 450`, assuming a 900 deg lock-to-lock steering wheel. This is an assumption, not a measurement.
- **Brake units:** CARLA `brake` is normalized in [0, 1]. We convert to MPa with `brake x 5`, assuming 5 MPa max brake pressure. CARLA provides no true brake pressure.
- **Throttle units:** CARLA `throttle` in [0, 1] is converted to % with `x 100`.
- **Lane centre:** taken from the CARLA map waypoint centre; approximate on curved segments.
- **Yaw reference:** yaw angle and yaw acceleration are relative to the vehicle heading at the TOR (planned).
- **Standardisation:** every metric is z-scored against a per-preset human baseline before PCA weights are applied.
