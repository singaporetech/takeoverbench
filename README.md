# TakeoverBench

A benchmarking tool for takeover systems in Autonomous Vehicles.

## Repository Structure

This repository is split into two main applications:
* **[Dashboard Server](./dashboard-server/)**: The Flask backend that processes simulation and calibration data.
* **[HMI Customizer](./hmi-customizer/)**: The native Android application acting as the human-machine interface.

## Getting Started
Please navigate to the respective directories above for detailed setup and installation instructions for each component.
